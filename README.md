# ⚡ DELTA MARKET · 三角洲行动实时物价

三角洲行动（Delta Force）游戏实时物价追踪网站。

## ✨ 功能
- 📊 24小时实时价格曲线
- 🔍 物品搜索 / 分类筛选
- 📈 涨跌统计记录
- 🎨 渐变极光背景 + 响应式设计
- 🔔 音效开关

## 📁 文件结构
```
delta-market/
├── index.html          # 主页
├── css/style.css       # 样式
├── js/app.js           # 逻辑（价格追踪/图表）
└── data/
    ├── prices.json      # 物品价格数据
    └── prices_real.json # 真实交易行数据
```

## 🚀 在线预览
访问 https://Yz333zY.github.io/delta-market/ 查看效果（需在 GitHub 仓库 Settings → Pages 开启）

数据来自三角洲数据帝实时交易行，仅供参考。
